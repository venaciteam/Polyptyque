> **Version bêta.** Quatrième bêta de Polyptyque, ce n'est pas encore la 1.0 définitive. Pour un enregistrement important, garder un œil sur les fichiers.

## Nouveautés

- **Une même source dans plusieurs scènes** : clic droit sur une source > « Copier » (ou <kbd>Ctrl</kbd> + <kbd>C</kbd>), choisir une autre scène, puis « Coller » (ou <kbd>Ctrl</kbd> + <kbd>V</kbd>). C'est la même source dans les deux scènes, pas une copie : même fenêtre et, pour un navigateur, mêmes connexions et mêmes onglets. La supprimer d'une scène ne la retire pas des autres, et la liste signale les sources partagées (« · 2 scènes »). Une même source ne peut pas figurer deux fois dans une scène.
- **Dupliquer une scène** : nouveau bouton dans le panneau des scènes. La nouvelle scène reprend les mêmes sources, dans le même ordre.
- **Réordonner les sources par glisser-déposer**, dans la liste des sources ou directement dans la grille des aperçus. Les flèches restent disponibles, au clavier notamment.

## Télécharger

- **Polyptyque-Setup.exe** : installation sans question ni droits administrateur.
- **Polyptyque-portable.zip** : sans installation ; décompresser où l'on veut, puis lancer `Polyptyque.exe`.

Windows 10 (2004 ou plus récent) ou Windows 11, 64 bits. Polyptyque n'est pas encore signé : si Windows affiche « Windows a protégé votre ordinateur », cliquer sur « Informations complémentaires », puis « Exécuter quand même ».

## Mises à jour

Les copies en bêta 1, 2 et 3 la reçoivent d'un clic dans Polyptyque, jamais pendant un enregistrement. Scènes, sources et connexions sont reprises telles quelles : le fichier des réglages passe à un nouveau format au premier lancement, et l'ancien reste dans les sauvegardes. Cette bêta reçoit les bêtas suivantes, puis la 1.0 stable. Le choix se fait dans Réglages > Mises à jour.

## Limites connues

- Revenir à une bêta précédente après celle-ci ramène les réglages d'avant la mise à jour (restaurés depuis les sauvegardes) : les changements faits depuis sont perdus.
- Pendant un glisser-déposer, la liste des sources ne défile pas toute seule : pour un grand déplacement, passer par la grille des aperçus, qui montre toutes les sources.
- Les enregistrements programmés ne démarrent que si Polyptyque est ouvert et l'ordinateur allumé : Windows ne lance pas encore Polyptyque à l'heure prévue, ni ne sort l'ordinateur de veille.
- Pas encore vérifié : le démarrage d'un enregistrement programmé avec la session Windows verrouillée et l'écran éteint.
- Version portable : l'option « Lancer Polyptyque au démarrage de Windows » est inscrite dans Windows ; la couper avant d'emporter le dossier sur un autre PC.
- Le son est isolé par programme, pas par onglet.
- Une fenêtre réduite dans la barre des tâches a une image figée (bouton « Rétablir la fenêtre » sur sa carte).
- Contenus protégés (Netflix…) souvent en noir ; jeux en plein écran exclusif en noir.
- Si le navigateur d'une source a plusieurs fenêtres, seule celle de la source revient au lancement suivant quand Polyptyque les ferme ; les autres restent dans « Fenêtres récemment fermées » de l'historique du navigateur.
- Rare : si Polyptyque ne démarre plus après une mise à jour (par exemple un antivirus qui bloque le remplacement des fichiers), le réinstaller avec Polyptyque-Setup.exe. Scènes, réglages et connexions sont conservés.

## Signaler un problème

Onglet **Issues** du dépôt, en joignant si possible le journal : `%LOCALAPPDATA%\Polyptyque\journaux`, ou `données\journaux` pour la version portable.
