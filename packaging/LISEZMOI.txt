POLYPTYQUE - VERSION D'ESSAI
============================

Polyptyque enregistre plusieurs fenêtres en même temps, chacune dans son
propre fichier, avec uniquement le son de cette fenêtre.

Installation
------------
Polyptyque-Setup.exe installe Polyptyque sans question ni droits
administrateur (raccourcis sur le Bureau et dans le menu Démarrer). Les
nouvelles versions sont proposées d'un clic dans Polyptyque. La
désinstallation (Paramètres de Windows > Applications) conserve scènes,
réglages et connexions des navigateurs.

Contenu
-------
- polyptyque.exe         : Polyptyque, avec son interface
- polyptyque-console.exe : la version en console de l'étape 0 (mêmes
                           réglages, mêmes scènes)
- ffmpeg.exe             : l'encodeur vidéo utilisé par Polyptyque (doit
                           rester à côté)
- LICENSE.txt    : licence de Polyptyque (GPL v3)
- FFMPEG-LICENSE.txt : licence de FFmpeg

Prérequis
---------
- Windows 10 version 2004 ou plus récent, ou Windows 11 (64 bits).
- Carte NVIDIA : pilote 570 ou plus récent. Les cartes AMD et Intel, ou
  l'encodage par le processeur, fonctionnent aussi.

Premier lancement
-----------------
Windows peut afficher « Windows a protégé votre ordinateur » : le programme
n'est pas encore signé numériquement. Cliquer sur « Informations
complémentaires », puis « Exécuter quand même ».

Utilisation
-----------
1. Lancer polyptyque.exe.
2. Sources → « Navigateur » : choisir le navigateur, un nom, une adresse.
   Polyptyque ouvre ce navigateur avec un profil qui lui est propre :
   s'y connecter, préparer ses onglets. Connexions et onglets sont conservés.
   Tout son joué dans ce profil sera enregistré dans le fichier de la source.
3. Sources → « Application » : choisir une fenêtre ouverte (Discord, jeu,
   Tor Browser…).
4. « Démarrer l'enregistrement ». Polyptyque retrouve ou rouvre les fenêtres,
   puis affiche l'état de chaque source. « Tout arrêter » finalise les
   fichiers.
5. Le bouton rond de chaque aperçu démarre ou arrête cette seule source,
   même pendant un enregistrement (une source ajoutée en cours de route
   commence un nouveau fichier).

Raccourcis clavier (modifiables dans les réglages, actifs même quand
Polyptyque est en arrière-plan) :
- Ctrl+Maj+F9  : démarrer ou arrêter l'enregistrement
- Ctrl+Maj+F10 : afficher ou réduire Polyptyque
- Ctrl+Maj+F11 : activer ou couper les aperçus

Les fichiers sont dans le dossier Vidéos\Polyptyque (modifiable dans les
réglages), un fichier MKV par source.

Montage (Premiere Pro…)
-----------------------
« Convertir en MP4… » crée une copie MP4 sans perte de qualité à côté de
chaque MKV choisi (le MKV est conservé). Les réglages permettent aussi de
convertir automatiquement à la fin de chaque enregistrement. La copie
double la place occupée sur le disque.

Micro
-----
Désactivé par défaut. Dans les réglages : « Enregistrer mon micro dans un
fichier séparé », puis choisir le micro. Le son du micro est enregistré
dans « …_Micro.mka » (converti en .m4a pour le montage). Windows doit
autoriser l'accès au micro pour les applications de bureau : Paramètres >
Confidentialité et sécurité > Microphone.

À savoir
--------
- Une fenêtre réduite dans la barre des tâches ne se filme plus (image
  figée). Une fenêtre cachée derrière une autre se filme normalement.
- Si une fenêtre se ferme pendant l'enregistrement, l'image devient noire et
  la source est rattachée automatiquement dès que la fenêtre revient.
- La mise en veille automatique est empêchée pendant l'enregistrement. Une
  mise en veille demandée (capot fermé, bouton, menu) reste possible : à
  éviter pendant un enregistrement.
- Fermer Polyptyque pendant un enregistrement demande une confirmation,
  puis finalise les fichiers avant de quitter.
- Éteindre ou redémarrer Windows pendant un enregistrement : Windows affiche
  que Polyptyque enregistre et permet d'annuler. Si l'arrêt est forcé, les
  fichiers sont finalisés au mieux avant la fermeture.
- Si l'encodeur s'arrête en cours de route, Polyptyque le relance tout seul :
  la suite est dans un fichier « …_partie2.mkv » (environ une seconde
  perdue entre les deux).

En cas de problème
------------------
Les journaux sont dans :
  %LOCALAPPDATA%\Polyptyque\journaux
(copier ce chemin dans la barre d'adresse de l'Explorateur).
Chaque enregistrement a son dossier « session_… » avec un journal par source.
